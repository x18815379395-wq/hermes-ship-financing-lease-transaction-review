# 船舶融资租赁交易审查

审查船舶建造、租赁、运营、物权、处置及财务回报。

## 安装

方式一（通过Hermes技能中心）：

```bash
hermes skills install https://raw.githubusercontent.com/x18815379395-wq/hermes-ship-financing-lease-transaction-review/main/SKILL.md
```

方式二（手动安装，从GitHub克隆）：

```bash
git clone https://github.com/x18815379395-wq/hermes-ship-financing-lease-transaction-review.git ~/.hermes/skills/financial-risk/ship-financing-lease-transaction-review
hermes reload-skills
```

> 注意：`hermes skills install` 方式需要Hermes Agent支持从GitHub URL安装SKILL.md。若不支持，请使用手动克隆方式。

## 使用方法

覆盖船舶估值方法（市场比较法/成本法/收益法，含加权平均与差异处理）、船舶建造合同审查、船级社与IMO规范、跨境登记与抵押、运营现金流与TCE测算、处置净值与残余价值保障、10项风险提示。

具体使用方法请参考技能的 `SKILL.md` 文件。
