# 船舶财务模型口径

脚本：`scripts/vessel_finance_model.py`。全部金额使用同一自定义单位。

## 1. 核心公式

- 可用天数 = 年天数 − 计划停租天数 − 当年坞修额外停租天数 − 情景额外停租天数。
- 收入天数 = 可用天数 × 利用率。
- TCE收入 = 日TCE × 收入天数。若输入为航次总收入，须先扣航次费用/佣金后再换算TCE，禁止把航次毛收入直接填入。
- 船舶OPEX = 日OPEX × 年天数；不因停租自动消失。
- CFADS = TCE收入 − OPEX − 管理费 − 坞修/特检CAPEX − 环保改造CAPEX。
- 项目/权益现金流、DSCR与LLCR口径同脚本明细；到期残值扣除销售费用。
- 经营盈亏平衡TCE = 全期OPEX、管理费、坞修和环保CAPEX / 全期收入天数。
- 含债务服务盈亏平衡TCE = 上述成本加全期债务本息 / 全期收入天数。
- LTV = 债务余额/同期可实现船价；当前脚本汇总列示初始债务/购买价，正式项目需逐期导入估值曲线。
- 公开收益主张复核：经营利润=`(年收入－含折旧运营费用)×持有年数`；处置收益=`售价－处置时账面价值`；现金OPEX=`含折旧运营费用－折旧`；现金利润=`经营现金流×持有年数＋净售价－初始购价`。
- 累计ROI=`累计利润/初始投资`，不反映时间价值；项目IRR必须基于逐期现金流求根，不得用累计ROI替代。
- 市场法简单均值=`Σ比准价/可比数`；加权均值=`Σ(比准价×权重)/Σ权重`。权重必须反映案例相关性并留痕。
- 成本法价值=`重置成本－实体性贬值－功能性贬值－经济性贬值`。
- 方法差异率（相对市场法）=`(市场法加权值－成本法值)/市场法加权值`。差异超过20%仅触发复核，不自动决定采用哪一方法。

## 2. 模型输出

逐年输出可用/收入天数、TCE、收入、OPEX、管理费、坞修、环保CAPEX、CFADS、债务本息、DSCR、项目与权益现金流；汇总输出NPV、项目/权益IRR、LLCR、最低DSCR、盈亏平衡TCE、初始LTV和风险旗标。

## 3. 压力测试

可配置TCE倍率、OPEX倍率、残值倍率和额外停租天数。正式项目至少运行：TCE下降、利用率/停租恶化、OPEX上涨、坞修超支、环保改造、残值下降、扣押/制裁停航及组合压力。复杂组合可直接在单一情景中叠加倍率。

## 4. 审计纪律

1. 期租、航租、光租现金流边界必须先统一；航次费用不得在TCE口径下重复扣除。
2. OPEX通常按拥有/运营天数发生，不得按收入天数同比例压低。
3. 坞修既影响现金支出又影响收入天数，二者必须同时建模。
4. 船价、拆船值和司法处置净值分列；后者需扣优先权、留置、保管、拍卖和时间折价。
5. DSCR不得无条件计入残值；气球还款须单独审查。
6. 航运公司合并现金流不能替代单船SPV现金流，反之亦然。
7. 年折旧×持有年数必须与累计折旧勾稽；如不同，须识别首尾期间不足一年、资产已提足折旧或原文口径错误。
8. 日租金与年收入、日OPEX与年现金OPEX应分别反推收入天数和成本天数；差异需由停租、成本发生基础或口径边界解释。
9. 未计税、融资、坞修/特检、环保CAPEX、佣金、停租和出售成本的高回报只能列为未杠杆税前粗算。
10. 可比船至少三艘，逐项修正交易时间、交易条件、船型/DWT、船龄、船厂、机型、船级、特检/坞修、环保配置和租约负担；报价与成交价分层。
11. 成本法须说明更新重置或复原重置，并防止实体、功能、经济贬值重复扣减；市场法与成本法不得机械平均。
12. 评估价值不等于可实现售价；融资第二还款来源另扣经纪、维修、扣押保管、优先费用、税费和处置周期折价。

## 5. 当前版本限制

- 年度离散、等额本金模型；未实现逐航次燃油/港费、浮息、税务、汇率及复杂气球还款；
- 假定输入TCE已扣航次费用和佣金，使用者须在底稿中复算；
- 未自动接入AIS、PSC、船级、制裁、运价指数或船价数据库；
- 未模拟CII速度下降对收入天数、燃油与运价的联动；
- `valuation_crosscheck`仅作算术、权重和方法差异审计，不替代逐船可比性判断、验船或独立估值报告；
- `equity_irr`仅在现金流存在有效IRR根时返回数值，否则为null；
- 正式审批应扩展逐月/逐航次模型，并由独立模型复核人抽查。
